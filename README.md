## 🧭 About this repository

One website, built with obsessive discipline. The first project,
**`html_advanced`**, builds a full multi-page magazine — home, about,
article, contact, latest news, style guide — using nothing but semantic
HTML5, in ~40 incremental steps you can diff file-by-file.

The second project, **`CSS_advanced`**, styles those same pages with 32
progressive stylesheets: from a reset and `@font-face` to specificity
battles, positioning, flexbox/grid layouts and responsive media queries.

No frameworks. No preprocessors. Just the platform — learned the way the
platform works.

## 📚 The projects

| Project | What it covers |

## 🛠️ Environment

- Any modern browser — no build step, no server required
