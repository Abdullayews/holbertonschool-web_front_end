## 📖 About this project

The sequel to `html_advanced`: the finished semantic pages now get a
**professional visual design**, one stylesheet at a time. `styles/N-style.css`
grows from a reset and font-face declarations to a complete responsive
layout — the numbered files are a stop-motion film of a design system being
born.

Real-world topics are covered as they come up: custom fonts with
`@font-face`, the **specificity** wars, `z-index` stacking contexts, the
**grid/flexbox** decision, pseudo-classes and pseudo-elements, transition
vs transformation, and media queries for every breakpoint.

## 🎯 Concepts covered

- CSS resets and `@font-face` custom typography
- Selectors, specificity and cascade order
- Display modes: block, inline-block, flex, grid
- Box model mastery: margin, padding, border, sizing strategies
- Positioning: relative, absolute, fixed — and stacking contexts
- Pseudo-classes (`:hover`, `:focus`, `:nth-child()`) & pseudo-elements
- Media queries and responsive breakpoints
- Transitions & transforms — motion, tastefully

## 📂 Repository layout

| Path | Contents |
|---|---|
| `styles/1-style.css … 32-style.css` | The 32-step styling progression |
| `images/` | Logos, favicon, article & team photos |
| *(pages)* | The HTML lives in the sibling `html_advanced` project |

Each numbered stylesheet can be applied to the same HTML — swap the link
and watch the site evolve from wireframe to magazine.
