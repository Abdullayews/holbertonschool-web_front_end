## 📖 About this project

This project builds a full multi-page **magazine website** — home, about,
article, contact, latest news and a style guide — using nothing but
**semantic HTML5**. No styling yet; structure *is* the assignment.

The workflow is deliberately incremental: each `N-index.html` adds one
layer of semantics — first the `<head>` with meta, favicon and Open Graph,
then `header` / `main` / `footer` landmarks, navigation, `article` and
`section` regions, `figure` + `figcaption`, tables for data, forms with
labels and accessibility attributes. You can literally diff two consecutive
files and see one concept appear.

## 🎯 Concepts covered

- Semantic landmarks: `header`, `main`, `footer`, `nav`, `aside`
- The `<head>` done right: meta charset, viewport, description, OG tags, favicon
- `article` vs `section` vs `div` — the eternal question, answered
- Accessible media: `figure`, `figcaption`, alt text that means something
- Data tables: `thead`, `tbody`, `caption`, scope attributes
- Forms: labels, fieldsets, placeholders, validation attributes
- W3C validation as a build gate
